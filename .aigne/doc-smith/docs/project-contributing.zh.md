# 贡献与支持

欢迎来到 Tokio 社区！无论您是寻求帮助、报告错误，还是希望贡献代码，本指南都将为您提供参与项目所需的资源。

## 获取帮助

如果您在使用 Tokio 时遇到问题，我们鼓励您通过以下资源寻求解答。许多常见问题已在我们的官方文档中得到解答。

- **[指南](https://tokio.rs/tokio/tutorial)**：官方教程是开始学习 Tokio 及其概念的最佳起点。
- **[API 文档](https://docs.rs/tokio/latest/tokio)**：获取关于特定函数、结构体和模块的详细信息。

如果在文档中找不到答案，我们活跃的社区随时准备提供帮助：

- **[Discord 服务器](https://discord.gg/tokio)**：加入我们活跃的 Discord，与其他用户和维护者进行实时交流。
- **[GitHub Discussions](https://github.com/tokio-rs/tokio/discussions)**：在这里提问、分享想法，并与社区进行更深入的讨论。

## 为 Tokio 做贡献

:balloon: 感谢您帮助改进项目！我们非常欢迎您的加入！我们有一份[贡献指南](https://github.com/tokio-rs/tokio/blob/master/CONTRIBUTING.md)，可以帮助您参与 Tokio 项目。请阅读该指南，了解我们的开发流程、如何提出错误修复和改进建议，以及如何构建和测试您所做的更改。

### 贡献许可

本项目采用 MIT 许可证。除非您另有明确声明，否则您有意提交给 Tokio 的任何贡献都将根据 MIT 许可证授权，不附带任何附加条款或条件。

## 项目策略

为确保稳定性和可预测的开发周期，Tokio 项目遵循以下策略。

### 支持的 Rust 版本 (MSRV)

Tokio 维护一个滚动的最低支持 Rust 版本 (MSRV) 策略。当我们提高 MSRV 时，新的 Rust 版本必须已发布至少六个月。此策略适用于次要版本发布；我们不在补丁版本发布中提高 MSRV。

**当前 MSRV 为 1.70。**

以下是过去次要版本的 MSRV 历史记录：

| Tokio 版本 | MSRV      |
|---------------|-----------|
| 1.39至今   | Rust 1.70 |
| 1.30至1.38  | Rust 1.63 |
| 1.27至1.29  | Rust 1.56 |
| 1.17至1.26  | Rust 1.49 |
| 1.15至1.16  | Rust 1.46 |
| 1.0至1.14   | Rust 1.45 |

### 发布计划

Tokio 没有固定的发布计划，但我们通常每月进行一次次要版本发布。我们会根据需要发布用于修复错误的补丁版本。

### 长期支持 (LTS) 与错误修复策略

我们将特定的次要版本指定为长期支持 (LTS) 版本。关键的错误修复将被向后移植到所有活跃的 LTS 版本。每个 LTS 版本将获得至少一年的修复支持。

如果您需要在项目中依赖一个固定的次要版本，我们强烈建议您使用 LTS 版本。

**当前的 LTS 版本：**

| 版本    | 支持截至      | MSRV      |
|---------|-----------------|-----------|
| `1.43.x`  | 2026年3月      | Rust 1.70 |
| `1.47.x`  | 2026年9月      | Rust 1.70 |

要使用特定的 LTS 次要版本，您可以在 `Cargo.toml` 文件中使用波浪号 (~) 进行指定，它将匹配该次要版本的最新补丁版本。

```toml Cargo.toml icon=logos:rust
tokio = { version = "~1.43", features = ["full"] }
```

| `1.14.x` | 2022年6月         |
